# Curvas

A cidade dispõe de vários formatos de vias: rodovias, estradas de terra, etc. Considere os exemplos abaixo para adaptar técnicas durante um acompanhamento.

{% stepper %}
{% step %}
### <mark style="color:yellow;">Curvas Rápidas</mark>

O piloto entra na curva, passa pelo ápice e, em seguida, mantém sua linha praticamente reta até o ponto de saída.

{% embed url="https://www.youtube.com/watch?v=vQCurQK3UV0&embeds_referring_euri=https%3A%2F%2Fcdn.iframe.ly%2F" %}
{% endstep %}

{% step %}
### <mark style="color:yellow;">Curvas em 90º</mark>

O método clássico é frear antes, entrar na curva e acelerar o mais cedo possível, passando pelo ápice visando obter uma boa saída.

{% embed url="https://www.youtube.com/watch?v=drcgU0nIpVc&embeds_referring_euri=https%3A%2F%2Fcdn.iframe.ly%2F" %}
{% endstep %}

{% step %}
### <mark style="color:yellow;">Curvas de raio constante</mark>

O piloto entra cedo na curva e utiliza toda a aderência e aerodinâmica do carro para se manter próximo à tangência. Assim que o piloto visualiza o ponto de saída da curva, ele retoma a aceleração buscando o ponto de saída.

{% embed url="https://www.youtube.com/watch?v=6PV6biPW32I&embeds_referring_euri=https%3A%2F%2Fcdn.iframe.ly%2F" %}
{% endstep %}

{% step %}
### <mark style="color:yellow;">Curvas de ápice duplo</mark>

Nesse tipo de situação, devemos encaixar a saída de uma curva com a entrada da próxima.

{% embed url="https://www.youtube.com/watch?v=QLxZgzF7QGA&embeds_referring_euri=https%3A%2F%2Fcdn.iframe.ly%2F" %}
{% endstep %}

{% step %}
### <mark style="color:yellow;">Grampo / Hairpin</mark>

Freie em linha reta, mantendo o carro o mais externo possível na aproximação. Só então faça um ponto de entrada tardia, sacrificando a velocidade inicial da curva para poder acelerar o quanto antes e ter uma saída com velocidade.

{% embed url="https://www.youtube.com/watch?v=EKBxlvDjQLE&embeds_referring_euri=https%3A%2F%2Fcdn.iframe.ly%2F" %}
{% endstep %}

{% step %}
### <mark style="color:yellow;">Sequência em S</mark>

O piloto apenas aponta para o ápice da primeira curva após a aproximação e segue sem nenhuma mudança de trajetória até a saída da sequência.

{% embed url="https://www.youtube.com/watch?v=GYaaiRxkxns&embeds_referring_euri=https%3A%2F%2Fcdn.iframe.ly%2F" %}
{% endstep %}

{% step %}
### <mark style="color:yellow;">Curva após Chicane</mark>

O piloto terá que continuar freando ao longo do ápice da primeira curva rápida para ter uma velocidade compatível com a entrada da curva lenta seguinte.

{% embed url="https://www.youtube.com/watch?v=cyOdY2ATMlU&embeds_referring_euri=https%3A%2F%2Fcdn.iframe.ly%2F" %}
{% endstep %}

{% step %}
### <mark style="color:yellow;">Reta longa após duas curvas idênticas</mark>

O piloto também terá que continuar freando ao longo do ápice da primeira curva rápida para ter uma velocidade compatível com a entrada da curva lenta seguinte.

{% embed url="https://www.youtube.com/watch?v=KpfCorUeDKs&embeds_referring_euri=https%3A%2F%2Fcdn.iframe.ly%2F" %}
{% endstep %}
